# LeadHer 🌸

LeadHer is a full-stack web platform created to empower, inspire, and connect women. The platform provides a space where women can discover opportunities, stay informed about upcoming events, and engage with meaningful journal content focused on growth, empowerment, and personal development.

The goal of LeadHer is to create a supportive digital community that encourages women to lead, grow, connect, and thrive.

## ✨ Features

### 📅 Events

Users can view and stay updated with upcoming events created for women. Events can include workshops, networking opportunities, empowerment sessions, community gatherings, and other activities.

### 📖 Journal

The platform includes a journal section featuring articles and content focused on topics such as:

* Personal growth
* Women's empowerment
* Leadership
* Career development
* Motivation and inspiration
* Lifestyle and wellbeing

### 👩🏽‍💼 Empowerment

LeadHer was created with the vision of providing women with access to information, opportunities, events, and content that supports their personal and professional growth.

### 🔐 Administration

Administrators can manage platform content through protected backend API endpoints, allowing content such as events and journal posts to be created and maintained.

## 🚀 Getting Started

### Prerequisites

Before running the project, make sure you have the following installed:

* Node.js
* npm
* .NET SDK
* SQL Server

### Frontend Setup

Navigate to the frontend directory:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

### Backend Setup

Navigate to the backend directory:

```bash
cd backend
```

Restore dependencies:

```bash
dotnet restore
```

Configure your database connection in `appsettings.json`.

Run the application:

```bash
dotnet run
```

## 🔗 API

The React frontend communicates with the ASP.NET Core Web API to retrieve and manage application data.

The API handles functionality related to:

* Events
* Journal content
* Authentication
* Administrative access
* Database operations
